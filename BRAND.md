# İÜ ATS brand

ATS is the Alumni Tracking System, an Istanbul University Web Programming
course project. The short name is **IU ATS** in English and **İÜ ATS** in Turkish, with the
descriptor **Alumni Network**.

## Audience and tone

Alumni and students visit for university announcements and career opportunities.
Staff use the workspace to manage the existing records. Mentorship, events,
authentication and approval workflows follow the README roadmap.

The Beyond the Years identity is warm, calm and people-centered. The public
home tells the story from student life to lasting community. Workspace copy
explains the action and its result directly.

## Copy

- The interface is in English and Turkish. Write the English text first and add
  its Turkish translation to `backend/public/i18n.js`; a text without one stays
  English. Records from the database and the API's error messages are not
  translated. Preserve Turkish spelling in İstanbul Üniversitesi; the short name is
  "IU ATS" in the English source text and "İÜ ATS" in its Turkish translation.
- In Turkish the descriptor is **Mezun Ağı** and the system is **Mezun Takip Sistemi**.
- Use action labels such as Browse opportunities, Save posting and Delete user.
- Link labels identify existing destinations. Represent future functionality
  as planned until implemented.
- Validation errors explain the issue and how to correct it. Server errors use
  a safe message with a recovery action.
- Show database statuses in badges and explain them in plain language elsewhere.
- Use day, abbreviated month and year for dates, and 24-hour times.
- Use synthetic demo data. Never invent real alumni testimonials or achievements.

## Identity

Instrument Serif headings and Inter body text establish the editorial style.
Warm ivory, midnight navy, burgundy and champagne are defined in
[DESIGN.md](DESIGN.md). The project emblem and generated photographs are
illustrative assets.

The week 8 visual study used the Beyazıt gate. The current identity follows
the people and connections in each chapter.
